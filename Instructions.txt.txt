Instructions:
1) The datasets are contained in the files Circle.mat and Spiral.mat and the user must save them in the same folder as the CODE.mlx file and the Matlab functions.
2) The CODE.mlx file contains the Matlab code to run to obtain the presented results. The file is divided into sections, one for each task. To reproduce the reported results the user must run the code and input the required parameters: 
-first, the user is asked to select the number k of neighbours for the similarity graph. To reproduce the results the user must input 10, 20 or 40. The default value is 10.
-secondly, the user is asked to select the dataset to run the code with. To reproduce the results the user must input Circle.mat or Spiral.mat . The default setting is Circle.mat .
- thirdly, the user is asked to select another number M of clusters to repeat the computations with. The user can enter a positive integer number  of his choice. The default value is 5.
- finally, the user is asked to select the number of clusters to repeat the computations with using the normalized laplacian matrix. The user can enter a positive integer number  of his choice. The default value is 3. 
3) The other files are the implemented Matlab functions that are called inside the CODE.mlx file. For the CODE.mlx file to run, all the functions must be saved by the user in the same folder as the main code file and the datasets. The implemented functions are the following:
- inverse_power_method : implements the inverse power method
- deflation_method : implements deflation method
- compute_m_smallest_eigenvalues : computes eigenpairs of a matrix using deflation and inverse power method
